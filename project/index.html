Modern Register and Login Page - Case Study

Project Overview

Designed a modern login and registration experience for a fictional mobile application. The goal was to create a clean and intuitive onboarding flow that reduces friction for first-time users.

Objective

The project focused on creating a visually appealing authentication experience while maintaining clarity and ease of use.

Design Considerations

  • Simplicity: Users should immediately understand how to log in or create an account.
  • Visual Clarity: Maintain a clean and modern aesthetic that reduces cognitive load.
  • Mobile-first Design: The layout was optimized for mobile devices.
  • Clear Call-to-Action: Prominent and easily identifiable buttons for login and registration.
  • Accessibility: Input fields and buttons were designed with sufficient size and contrast.

Wireframe

Design Decisions

  1. Large Primary CTA
    • Decision: Use prominent Sign up and Login button
    • Reason: Directs user attention to the primary action.
  2. Alternative sign up/sign in options
    • Decision: Offer Google and Apple sign in options.
    • Reason: Allow users to sign in with their existing accounts.
  3. Loading screen
    • Decision: Implement skeleton loading
    • Reason: Let user know that the page is loading properly.
  4. Consistent Colors
    • Decision: Consistent use of colors throughout the page.
    • Reason: To create a cohesive and professional look and feel.

Final Screen

This project helped me practice visual hierarchy, spacing, form design, and authentication flows. I learned how small UI decisions can significantly impact usability and user confidence.
